"# Kora Rwanda - Frontend" 
"" 
"A platform connecting Rwandan youth with scholarships, jobs, internships, and training opportunities." 
"" 
"## Tech Stack" 
"- React 18" 
"- Tailwind CSS" 
"- Vite" 
"- React Router" 
"" 
"## Setup" 
"1. Clone the repo" 
"2. Run \`npm install\`" 
"3. Run \`npm run dev\`" 
""

"This frontend requires the backend API to be running."
